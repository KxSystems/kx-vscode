| 4   | [Bug 4](https://github.com/KxSystems/kx-vscode/pull/799#pullrequestreview-5377450730) - `src/classes/replConnection.ts:1074`: `forLabel` can lose a running REPL after workspace folders are reordered or added, and start an orphaned duplicate.                                            | Fixed in part | Accurate only for two workspace folders of the same name, which nothing but their order tells apart, so the label (`ws`, `ws [2]`) is worked out from the current order every time it is read.
