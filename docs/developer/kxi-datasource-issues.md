## Unfiled — defects found while working this list (6)

None of these had a Jira issue. Each was found by exercising the code rather
than by reading a ticket, so each is recorded here with what made it reachable.

| Area    | Where                                        | What                                                                                                                                                                                                                                                                                                                                                  | State                                                                            |
| ------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| UDA     | `createUDAReturn`, `src/utils/uda.ts`        | Threw on a UDA registered without a return: `uda?.return.type` guards `uda`, not `return`, and `metaReturn` is optional in q. One such UDA in the meta took down `parseUDAList` and with it `parseQueryList`, leaving the editor with **no** APIs at all, builtins included.                                                                          | Fixed — worst of the set, for the blast radius                                   |
| UDA     | `isInvalidRequiredParam`, `processUDAParams` | `false` and `0` counted as "not answered". A required boolean could never be run as `false`, and an unchecked optional boolean was sent as `""`. The checkbox sets a real boolean (`renderCheckbox` → `setParam(param, checked)`), so this was reachable from the form, not only a hand edit.                                                         | Fixed — both now test `undefined`/`null`/`""` only                               |
| UDA     | `kdbQueryView.message`                       | A stored query was never given the distinguished parameters, unlike one picked from the dropdown. A query whose `query` had no `params` crashed every render; one lacking the distinguished set offered no table/labels/scope/startTS. Reachable through conversion — `toQuery` (queryCommand.ts:87) returns a converted datasource's `uda` verbatim. | Fixed — stored queries now get the same treatment                                |
| getData | `serializeRows`, `src/models/query.ts`       | A single `in` or `within` value was sent as a scalar, though "when using `in` or `within` this should be a list" ([getData](https://code.kx.com/insights/1.19/api/database/query/get-data.html)). `sym in AAPL` went out as `["in","sym","AAPL"]`. Two or more values were always right, which is why it survived.                                    | Fixed — `forcesList`, those two operators only                                   |
| Both    | `renderChoice`, `kdbQueryView.ts`            | An optional choice parameter deleted itself when its dropdown was opened: the `kdb-select` and the remove button shared one `<label>`, and a label forwards its click to its first labelable descendant — a custom element does not qualify. Reachable before this branch via the UDA distinguished `table`.                                          | Fixed — both choice renderers use a `div`, like `renderRows`                     |
| getData | `toValues`, `parseTables`                    | Filter values are coerced to numbers whenever they parse as one, because the row field cannot see the column's type: `sym = 600519` goes out as the number and cannot match. `meta.schema[].columns[].typ` carries the type and `parseTables` drops it. Carrying it through would also let KXI-70491's columns validate.                              | **Open** — file before working; the coercion is load-bearing for numeric columns |
